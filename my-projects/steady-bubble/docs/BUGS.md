| B029 | Towed array performance is constant at all depths — should vary with thermocline | Design/Gameplay | 2026-03-19 | **Current code:** `layerPenalty()` is binary — 40% loss crossing the layer, 1.0 otherwise. Towed `baseRange` is flat 4500wu regardless of depth. No depth-dependent performance curve. **Real world:** Towed array performance varies significantly with depth. Below the layer is optimal (deep sound channel, long ranges). At PD the array is in the surface duct — separated from deep contacts by thermocline, ranges should be shorter. Near the layer is good (direct path + CZ). The current flat range + binary layer penalty doesn't model this. **Suggested approach:** Scale `baseRange` by a depth-dependent multiplier: e.g. 0.6× at PD, 1.0× just below layer, 0.85× very deep. Also consider that a towed array physically trails ~300m behind and below the sub, so its effective depth differs from player depth. |
